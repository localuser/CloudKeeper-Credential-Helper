KNOWN ISSUES
------------
[!] Path 1 permanently blocked on this tenant config (AADSTS650057)
    Root cause: client_id 04b07795-8ddb-461a-bbee-02f9e1bf7b46 (MS Azure CLI public app)
    is not permitted to request tokens for the IAM Identity Center resource.
    Fix: see "Fix Path 1" task above.

[!] Portal HTTP API 401 with OIDC token
    The IAM Identity Center portal HTTP API (portal.sso.*.amazonaws.com) requires a
    SAML-exchange cookie token, not the OIDC accessToken. Path 2 therefore uses the
    boto3 SSO API (list_accounts / get_role_credentials) instead. The portal HTTP API
    is only needed if you want to enumerate SAML app instances beyond what boto3 exposes
    (e.g. non-account apps). See cli/aws/sso_client.py for the working approach.
